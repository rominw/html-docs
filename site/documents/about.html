ABOUT THIS PLACE

留页

让值得留下的页面，继续保持它原本的样子。

建立于 2026年7月24日 更新于 2026年7月29日

为什么是「留页」

不是每个想法都需要成为一篇格式统一的博客文章。有些内容依赖自己的排版， 有些需要一张图、一段交互，或者一套只属于那一页的阅读节奏。

留页想做的事情很简单：把这些页面留下来。它们可以彼此不同，不必服从同一套 模板；首页只负责让人找到它们，不负责把它们改造成相同的样子。

“留”不是囤积，而是选择。只有那些以后仍值得回看、分享或继续生长的页面， 才会被放在这里。

THREE SMALL RULES

每一页，都保留自己的形状。

01

独立

每篇内容都是完整的 HTML 文档，可以拥有自己的结构、字体、颜色与交互。

02

原样

发布过程只读取标题、摘要和日期，不重新包装，也不覆盖页面本身的表达。

03

可抵达

首页提供清晰的索引和搜索，让一份被留下的内容，在需要时仍能被找到。

HOW A PAGE STAYS

一页如何被留下

它不是复杂的内容管理系统，只是一条尽量短的发布路径。内容保留在文件里， Git 记录变化，Cloudflare 将它送到读者面前。

  1. 写成完整页面 一份带有标题、摘要和日期的独立 .html 文件。
  2. 放进文档目录 构建脚本读取元数据，自动更新首页索引并按日期排列。
  3. 交给 Git 记住 每次修改都有清晰历史，页面可以生长，也可以回到从前。
  4. 发布到网络 Cloudflare Workers Static Assets 自动构建并提供静态页面。
